# Portafolio de Frank Oviedo

Sitio estático con mi información profesional como desarrollador mobile junior: sobre mí, habilidades, proyectos, formación y contacto.

Sitio en vivo: https://seridem06.github.io

## Tecnologías

- HTML 5, CSS 3 y JavaScript sin frameworks
- [AOS](https://michalsnik.github.io/aos/) para animaciones de entrada
- Font Awesome e iconos de [Devicon](https://devicon.dev/) (copiados en `images/`)

## Estructura

```
index.html
css/        base, header, home, sections, footer
scripts/    script.js (menú móvil y sección activa)
images/     fondo, perfil e iconos
```

## Ejecutar en local

Abre `index.html` en el navegador o usa la extensión Live Server de VS Code.
